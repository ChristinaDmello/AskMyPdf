# Ask My PDF — RAG PDF Question Answering

A beginner-friendly **Retrieval-Augmented Generation (RAG)** web application built with Flask. Upload a PDF, ask questions about it in plain English, and get answers generated by a large language model that are grounded in the content of your document.

## Overview

Large language models don't know what's inside your files. Ask My PDF solves this with RAG: it splits your PDF into small chunks, finds the chunks most relevant to your question using vector similarity search, and passes only those chunks to the model as context. The model is instructed to answer **only** from that context and to say so when the answer isn't in the document.

Embeddings and vector search run locally on your machine. Only the question and the retrieved chunks are sent to the LLM through the [OpenRouter](https://openrouter.ai/) API.

## Features

- **PDF upload** — upload a text-based PDF (up to 16 MB) through the web interface.
- **Text extraction** — reads every page with `pdfplumber` and tags text with page markers.
- **Chunking** — splits text into ~800-character chunks with 100-character overlap so context isn't lost at boundaries.
- **Local embeddings** — converts each chunk into a 384-dimensional vector with the Sentence Transformers `all-MiniLM-L6-v2` model.
- **Vector search** — stores vectors in a FAISS index and retrieves the 3 most similar chunks for each question.
- **Grounded answers** — sends the question and retrieved chunks to an LLM via OpenRouter (default model: `openai/gpt-oss-20b:free`).
- **Transparent retrieval** — shows the chunks used to generate each answer, with their rank and L2 distance score.
- **Session-based workflow** — each browser session works with one document; click **Upload New PDF** to start over.
- **Friendly error messages** — for missing files, non-PDF uploads, oversized files, PDFs with no extractable text, a missing API key, and API failures.

## How It Works

```
PDF Upload → Text Extraction → Chunking → Embeddings → FAISS Index (saved to disk)
                                                              ↓
User Question → Question Embedding → FAISS Search (Top 3) → OpenRouter LLM → Answer
```

1. **Upload** a PDF through the web UI.
2. **Extract** text from each page with `pdfplumber`.
3. **Split** the text into overlapping chunks.
4. **Embed** each chunk with Sentence Transformers (`all-MiniLM-L6-v2`).
5. **Store** the vectors in a FAISS index, saved to `uploads/processed/`.
6. **Ask** a question — it is converted into an embedding with the same model.
7. **Retrieve** the 3 closest chunks from the FAISS index.
8. **Generate** an answer by sending the question and retrieved chunks to an LLM through OpenRouter.
9. **Display** the answer along with the retrieved context.

## Tech Stack

| Component | Technology |
|-----------|------------|
| Language | Python 3.10+ |
| Web framework | Flask (with Jinja2 templates) |
| PDF parsing | pdfplumber |
| Text chunking | Custom character-based splitter |
| Embeddings | Sentence Transformers (`all-MiniLM-L6-v2`) |
| Vector search | FAISS (`faiss-cpu`, `IndexFlatL2`) |
| Numerical arrays | NumPy |

| Configuration | python-dotenv |
| Frontend | HTML + CSS |

## Getting Started

### 1. Prerequisites

- Python 3.10 or higher
- An OpenRouter account and API key (see [step 5](#5-get-an-openrouter-api-key))

### 2. Clone the repository

```bash
git clone https://github.com/ChristinaDmello/AskMyPdf.git
cd AskMyPdf
```

### 3. Create and activate a virtual environment

**Windows (PowerShell):**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

> **Note:** The first time the app starts, Sentence Transformers downloads the `all-MiniLM-L6-v2` model (~90 MB). This only happens once.

### 5. Get an OpenRouter API key

1. Sign up or log in at [openrouter.ai](https://openrouter.ai/).
2. Go to [openrouter.ai/keys](https://openrouter.ai/keys) and create a new API key.
3. Copy the key — you'll add it to your `.env` file in the next step.

The default model (`openai/gpt-oss-20b:free`) is a free-tier model on OpenRouter. You can change it by editing `OPENROUTER_MODEL` in `utils/gemini_client.py`.

### 6. Configure environment variables

Create a `.env` file from the provided template:

**Windows (PowerShell):**

```powershell
copy .env.example .env
```

**macOS / Linux:**

```bash
cp .env.example .env
```

Open `.env` and replace the placeholder with **your own** OpenRouter API key:

```
OPENROUTER_API_KEY=your_openrouter_api_key_here
```

Optionally, set a Flask secret key (recommended if you deploy the app anywhere other than your own machine):

```
FLASK_SECRET_KEY=a-long-random-secret-string
```

> **Keep your key private.** `.env` is listed in `.gitignore` so it is never committed. Only edit `.env` — never put a real key in `.env.example`.

### 7. Run the application

```bash
python app.py
```

Then open your browser at **http://127.0.0.1:5000**.

> The app runs Flask's development server with `debug=True`. It is intended for local use, not production deployment.

## Usage

1. Click **Choose PDF file** and select a text-based PDF.
2. Click **Upload & Process** and wait for indexing to finish — the page shows how many chunks were created.
3. Type a question about the document.
4. Click **Get Answer** to see the AI-generated answer and the context chunks it was based on.
5. Click **Upload New PDF** to clear the session and work with a different document.

## Module Overview

| File | Responsibility |
|------|----------------|
| `app.py` | HTTP routes (`/`, `/upload`, `/ask`, `/clear`), upload validation, session management |
| `utils/pdf_extractor.py` | Opens the PDF with pdfplumber and extracts text page by page |
| `utils/chunker.py` | Splits text into ~800-character chunks with 100-character overlap |
| `utils/embedder.py` | Converts text into 384-dimensional vectors with `all-MiniLM-L6-v2` |
| `utils/faiss_store.py` | Builds, saves, loads, and searches the FAISS index |
| `utils/gemini_client.py` | Builds the prompt and calls the LLM through OpenRouter |
| `utils/rag_pipeline.py` | Connects all steps: PDF ingestion and question answering |

## Limitations

- Works best with **text-based PDFs**. Scanned or image-only PDFs have no extractable text (no OCR support).
- One active document per browser session.
- Embeddings run on the CPU, so processing large PDFs can take a while.
- Uploaded PDFs and their indexes are kept in `uploads/` and are not deleted automatically.
- Free OpenRouter models may be rate-limited or temporarily unavailable.
